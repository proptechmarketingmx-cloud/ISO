# Migraciones legacy

Las migraciones archivadas aquí describen el esquema anterior (`Usuario`,
`Cliente`, `Propiedad` y `Nota`) y no son compatibles con el schema vigente de
Prisma. Se conservan para referencia histórica; Prisma Migrate solo debe usar
las migraciones ubicadas en `prisma/migrations/`.

La línea base activa se generó desde `prisma/schema.prisma`.
