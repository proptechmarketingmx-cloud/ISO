## Reglas para el agente IA

1. No generar datos ejemplo
2. No generar datos de prueba
3. No generar usuarios ficticios
4. No generar leads ficticios
5. No generar contenido inventado
6. No generar propiedades ficticias
7. No generar inmuebles ficticios
8. No generar correos ficticios
9. No generar numeros de telefono ficticios
10. No generar direcciones ficticias
11. No inventar registros para poblar bases de datos.
12. No asumir la existencia de datos que no hayan sido proporcionados explícitamente.
13. No generar sentencias INSERT con información inventada.
14. No generar archivos .json, .sql, .csv o similares con contenido ficticio.
15. No mostrar ejemplos de registros simulados.
